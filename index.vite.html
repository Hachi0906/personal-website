3 步启动本项目
1

在项目根目录（d:\TRAE\坦克大作战）打开 PowerShell / CMD / 终端。

2

安装依赖（已装过可跳过）：npm install
然后启动开发服务器：npx vite --port 5175

3

终端会输出地址，点击或复制到浏览器： http://localhost:5175/index.vite.html

若你的端口被占用，把 5175 换成实际 Vite 输出的端口即可； 路由使用 #/xxx 格式，比如 #/skills 可直达「个人技能」页。
